# ۴. برنامه‌ی PLC: توضیح کد نردبانی و اینترلاک‌ها

کد کامل: [`plc/TampoPrinter_SV2.il`](../plc/TampoPrinter_SV2.il) (فرمت Instruction List برای WPLSoft/ISPSoft).
این بخش شبکه‌های کلیدی را به‌صورت نردبانی نشان می‌دهد و دلیل هر تصمیم را توضیح می‌دهد.

> ⚠️ **شماره‌ی دستگاه‌های ویژه** (D1030، D1336، M1029، M1030، M1078، M1104، M1336، M1337، D1343، D1353) از دفترچه‌ی برنامه‌نویسی سری ES2/EX2/SS2/SA2/SX2/SE/**SV2** برداشته شده‌اند. پیش از راه‌اندازی، آن‌ها را با نسخه‌ی دفترچه‌ای که با **فریمور PLC شما** می‌خواند تطبیق دهید. همین‌طور جهت پیش‌فرض DZRN و بیت‌های معکوس‌کننده‌ی جهت (M1305/M1306) را.

## ۴-۱ دستورهای حرکتی استفاده‌شده

| دستور | فرمت | کاربرد در این برنامه |
|---|---|---|
| `DDRVA S1 S2 D1 D2` | S1 = موقعیت مطلق (پالس، ۳۲ بیت)، S2 = فرکانس (Hz)، D1 = خروجی پالس، D2 = خروجی جهت | **تنها** دستور حرکت X و Y. هم برای سیکل اتومات، هم Jog (مقصد = Soft-Limit) و هم Go-To |
| `DZRN S1 S2 S3 D` | S1 = سرعت هوم، S2 = سرعت Creep، S3 = ورودی DOG، D = خروجی پالس | هومینگ دو مرحله‌ای |
| `DDRVI` | حرکت نسبی | **استفاده نشده**. `DDRVA` امن‌تر است: اگر حرکت قطع شود و دوباره شروع شود، به همان مقصد مطلق می‌رسد و خطای جمع‌شونده ندارد |
| `DZCP` | مقایسه‌ی ناحیه‌ای ۳۲ بیتی | تشخیص «در موقعیت» و «داخل ناحیه‌ی کلیشه» |
| `DMUL` و `DDIV` | ضرب و تقسیم ۳۲ بیتی | تبدیل mm به پالس و mm/s به Hz |

**مقیاس‌بندی:** HMI همه‌چیز را بر حسب میلی‌متر نشان می‌دهد و PLC آن را به پالس تبدیل می‌کند:

```
pulses = pos[0.1mm] × SCALE[p/1000mm] / 10000       (7000 × 33333 = 2.3e8 < 2^31 ✔)
Hz     = spd[mm/s]  × SCALE / 1000
pos    = D1030 × 10000 / SCALE                     (نمایش موقعیت جاری)
```

## ۴-۲ اینترلاک‌های ضدبرخورد (نسخه‌ی ۲)

```
 شبکه N04-2 :  پد بالای ارتفاع امن (M26)
 ──┤X2 ├──────────────────────────────────────────[SET M26]   کاملاً بالا
 ──┤↑X20├──┤/Y4├──────────────────────────────────[SET M26]   عبور رو به بالا
 ──┤↓X20├──┤ Y4├──────────────────────────────────[RST M26]   عبور رو به پایین
 ──┬┤X3 ├┬────────────────────────────────────────[RST M26]   پد پایین
   └┤X17├┘

 شبکه N04-4 :  مجوز حرکت X
 ──┤M26├──┤/X3├──┤/X17├──┤M20├────────────────────( M40 )

 شبکه N04-5 :  مجوز حرکت Y
 ──┬┤M26 ├┬──┤M20├────────────────────────────────( M42 )
   └┤/M30├┘            (پد بالای ارتفاع امن  یا  بیرون از ناحیه‌ی کلیشه)

 شبکه N04-6 :  پنجره‌های فرود زودهنگام
 ──┤M507├──┤M96├──[D90 ≤ D550]──┤M92├─────────────( M63 )   Pick
 ──┤M507├──┤M97├──[D90 ≤ D550]────────────────────( M64 )   Print

 شبکه N04-7 :  مجوز فرود Z
 ──┬┤M31├┬──┤M33├──┬──┤M24├──┤M20├────────────────( M41 )
   └┤M63├┘         │
 ──┬┤M32├┬──┤X16├──┘
   └┤M64├┘
```

* سنسور مگنتی فقط وقتی پیستون **از جلویش رد می‌شود** روشن است. برای همین «بالا یا پایین بودن» از **جهت شیر** (`Y4`) هنگام عبور تشخیص داده می‌شود.
* `D90` فاصله‌ی باقی‌مانده‌ی X تا مقصد است: `DSUB D200 D30` و بعد `DABS`. دستور `DABS` را در دفترچه‌ی SV2 تأیید کنید.

| خطر برخورد | لایه‌ی ۱ (سکانس) | لایه‌ی ۲ (Motion Block) | لایه‌ی ۳ (نظارت) |
|---|---|---|---|
| حرکت X وقتی پد پایین است | مرحله‌ها فقط بعد از `M26` جلو می‌روند | `DDRVA` X در سری با `M40` | **A10**: X در حرکت و پد زیر ارتفاع امن ⇒ توقف فوری |
| فرود روی قطعه حین حرکت X | پنجره‌ی `D550` | – | **A17**: سنسور Down و X در حرکت ⇒ توقف فوری |
| برخورد کاپ با پد روی کلیشه | ترتیب مراحل | `DDRVA` Y در سری با `M42` | **A10** برای Y |
| فرود پد روی کاپ | S20 فقط بعد از `M92` و `M33` | `Y4` در سری با `M41` که شامل `M33` است | A07 |
| فرود روی دست اپراتور | – | `M41` شاخه‌ی Print شامل `X16` | رله‌ی ایمنی تغذیه‌ی `Y4` را قطع می‌کند |
| سنسور Z معیوب | – | `M25` شامل `/X3` و `/X17` | **A09**: Up با Down، یا Safe با Down |

## ۴-۳ بلوک اجرای حرکت (N10)

```
 ──┬┤M45├┬──────────────────────────────────────────( M50 )
   └┤M46├┘
 ──┤M50├──┤M40├──┤/M54├──┤/M29├──[ DDRVA D10 D12 Y0 Y1 ]
 ──┤M54├──┤M40├──┤/M50├──┤/M29├──[ DZRN  D18 D20 X0 Y0 ]
 ──┤/M50├─┤/M54├─┤/M1336├───────────────────────────( M58 )   کانال آزاد
 ──┤M1029├─┬─┤M54├──[RST M54][SET M57]                        پایان هوم
           ├─┤M50├──[RST M45]                                 پایان حرکت
           └────────[RST M1029]
```

**چرا این بلوک باید در انتهای برنامه باشد؟** دستور پالس دلتا برای اجرای دوباره باید دست‌کم **یک اسکن** کنتاکتش OFF دیده شود. ترتیب «اول سکانس‌ها، بعد Motion Block» و شرط `M58` در هر فرمان تضمین می‌کنند که:

```
اسکن n  : حرکت تمام شد → RST M45 → M58 = 0
اسکن n+1: DDRVA کنتاکت OFF را می‌بیند → M58 = 1
اسکن n+2: سکانس مقصد جدید را می‌نویسد و SET M45 → DDRVA دوباره اجرا می‌شود ✔
```

نوشتن مقصد (`D200`) فقط در **لحظه‌ی فرمان** و فقط وقتی کانال آزاد است انجام می‌شود. پس مقصد در طول حرکت ثابت می‌ماند.

## ۴-۴ نمونه‌ی یک مرحله‌ی سکانس (الگوی تکراری)

```
 // S80 : X → Print
 ──[= D0 K80]──┤/M32├──┤/M45├──┤M58├──┤M40├──[DMOV D502 D200][MOV D522 D202][SET M45]
 ──[= D0 K80]──┤M32├──────────────────────────[MOV K90 D0]
```

هر مرحله‌ی حرکتی سه شرط دارد:

1. **در مقصد نیستم** (`/M32`). اگر محور از قبل در مقصد باشد، فرمان حرکت صادر نمی‌شود.
2. **فرمانی در جریان نیست** (`/M45`).
3. **کانال آزاد است و مجوز حرکت هست** (`M58` و `M40`).

## ۴-۵ Z و شیر دوبوبین

```
 ──┬┤M60├┬──┤M41├──────────────────────────────────( Y4 )   SOL DOWN  (+24V از رله‌ی ایمنی)
   └┤M61├┘
 ──┤/Y4├───────────────────────────────────────────( Y5 )   SOL UP    (+24V معمولی)
```

* دو بوبین هیچ‌وقت هم‌زمان روشن نمی‌شوند. بوبین‌ها **دائم** برق دارند (نه پالسی)، پس پس از قطع و وصل برق، وضعیت شیر با وضعیت PLC هماهنگ می‌شود.
* در E-Stop، رله‌ی ایمنی تغذیه‌ی Y4 را **سخت‌افزاری** قطع می‌کند. PLC هم M60 و M61 را Reset می‌کند و Y5 روشن می‌شود، پس پد بالا می‌رود.
* **Dwell از لبه‌ی تأیید سنسور** Down شمرده می‌شود (مرحله‌های S60 و S100)، نه از فرمان شیر.

## ۴-۶ توقف‌ها

| نوع | ماشه | مکانیزم | هوم حفظ می‌شود؟ |
|---|---|---|---|
| Stop پایان سیکل | X13 (NC)، M101، تغییر Mode، پایان بچ | `M91`. سکانس در S10 به Idle می‌رود | ✔ |
| Stop کنترل‌شده (کلاس B) | آلارم‌های فرایندی | Reset شدن درخواست‌ها، پس کنتاکت DDRVA قطع و محور با شیب Decel ترمز می‌کند | ✔ |
| Stop فوری (کلاس A و A′) | `M29` | `SET M1078` و `SET M1104` (قطع فوری پالس) و Reset درخواست‌ها | کلاس A: ✘ |
| E-Stop سخت‌افزاری | رله‌ی ایمنی | قطع تغذیه‌ی Y4، ENA درایورها و (با تأخیر) 48V | ✘ |

> توجه: `M1078` یک «Pause» است. اگر وقتی کنتاکت دستور هنوز ON است Reset شود، حرکت **ادامه پیدا می‌کند**. به همین دلیل در کد، `M1078` فقط وقتی Reset می‌شود که همه‌ی درخواست‌ها (`M50`، `M52`، `M54`، `M55`) خاموش باشند.

## ۴-۷ چک‌لیست راه‌اندازی (Commissioning)

1. **بدون تسمه:** جهت چرخش را با Jog چک کنید. «+» باید از سمت هوم دور شود. اگر برعکس است، جهت را در CL57 (DIP یا ProTuner) عوض کنید، نه در سیم‌بندی.
2. جهت DZRN را چک کنید. باید **به سمت** سنسور هوم برود. اگر نمی‌رود، M1305/M1306 یا تنظیم جهت درایور را طبق دفترچه اصلاح کنید.
3. درایورها را روی **4000 pulse/rev** بگذارید. مقیاس X با گیربکس ۱:۳: `D518 = 100000` (۱۰۰ پالس در mm). مقیاس Y: `D520 = 33333`. برای کالیبره کردن، ۶۰۰ mm حرکت دهید، با خط‌کش اندازه بگیرید و مقیاس را اصلاح کنید: `SCALE_new = SCALE × 600 / measured`.
4. بدون فشار هوا: `X15 = 0`، پس A06 باید فعال شود.
5. سنسورهای Z: پد بالا باید `X2 = 1` بدهد. پد روی کلیشه با **پد فشرده** باید `X3 = 1` بدهد. سنسور را در نقطه‌ای بگذارید که پد حدود ۵ تا ۱۵ mm فشرده شده باشد. سنسور **Safe (X20)** را در ارتفاعی بگذارید که پد از کاپ، لبه‌ی کلیشه و فیکسچر **دست‌کم ۱۰ mm** بالاتر باشد.
6. موقعیت‌های Pick و Print و مرزهای ناحیه‌ی کلیشه (`D508` و `D510`) را با Jog پیدا و در HMI ثبت کنید. **ناحیه را دست‌کم نصف قطر پد بزرگ‌تر از کاپ بگیرید.**
7. سیکل خشک: `M503 = 1` (Dry-Run). یک سیکل کامل بدون فرود Z اجرا کنید.
8. تست اینترلاک‌ها: در حالت دستی X را حرکت دهید و Z را با دست (شیر دستی) پایین بیاورید. باید A10 صادر شود و محور فوراً بایستد.
8-1. تنظیم هم‌پوشانی: اول با `M507 = 0` و `M506 = 0` سیکل را پایدار کنید. بعد `M507 = 1` و `D550` را از ۵ mm به بالا ببرید (بخش ۳-۴). در آخر `M506 = 1` (برداشت زودتر).
9. تست E-Stop در هر مرحله‌ی سکانس: پد باید بالا برود و محورها بایستند.
10. زمان سیکل را روی HMI ببینید. شتاب و سرعت را کم‌کم بالا ببرید تا CL57 آلارم Position Error ندهد، بعد ۲۰٪ عقب بکشید.
