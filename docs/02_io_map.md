# ۲. جدول تخصیص آدرس‌ها (I/O، M، D، T) — نسخه‌ی ۲ (طرح جدید)

PLC: **DVP-28SV11T2** (ورودی X0 تا X17 و خروجی Y0 تا Y13) + ماژول توسعه‌ی **DVP16SP11T** (ورودی X20 تا X27 و خروجی Y20 تا Y27).
ورودی‌ها به‌صورت **Sink** سیم‌بندی می‌شوند (سنسورها NPN هستند و S/S به +24V وصل است).
