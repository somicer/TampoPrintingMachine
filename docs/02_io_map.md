# ۲. جدول تخصیص آدرس‌ها (I/O, M, D, T)

PLC: **DVP-28SV211T**. ورودی‌ها X0 تا X17 (۱۶ ورودی) و خروجی‌ها Y0 تا Y13 (۱۲ خروجی ترانزیستوری NPN).
ورودی‌ها به‌صورت **Sink** سیم‌بندی می‌شوند (سنسورها NPN هستند و S/S به +24V وصل است).

## ۲-۱ ورودی‌های دیجیتال (X)

| آدرس | نام | نوع و سیم‌بندی | منطق | توضیح |
|---|---|---|---|---|
| X0 | X_HOME | القایی NPN-NO (پیشنهاد: NC) | 1 = روی DOG | ورودی DOG دستور DZRN برای محور X |
| X1 | Y_HOME | القایی NPN-NO | 1 = روی DOG | ورودی DOG دستور DZRN برای محور Y |
| X2 | Z_UP | SMC D-M9N | 1 = پد بالا | شرط اصلی اینترلاک حرکت X و Y |
| X3 | Z_DOWN | SMC D-M9N | 1 = پد روی کلیشه فشرده شده | شروع Dwell1 (و Dwell2 اگر سنسور دوم نصب نباشد) |
| X4 | X_DRV_OK | خروجی ALM درایور CL57 (اپتو) | **1 = سالم** | طوری سیم‌بندی کنید که قطع سیم هم فالت دیده شود |
| X5 | Y_DRV_OK | ALM درایور CL57 | **1 = سالم** | |
| X6 | X_OT_OK | دو لیمیت NC سری (جلو و عقب) | **1 = سالم** | Over-travel سخت‌افزاری محور X |
| X7 | Y_OT_OK | دو لیمیت NC سری | **1 = سالم** | |
| X10 | ESTOP_OK | کنتاکت کمکی رله‌ی ایمنی | **1 = سالم** | فقط برای مانیتورینگ. قطع اصلی سخت‌افزاری است |
| X11 | PEDAL | پدال پایی | لبه‌ی بالارونده | شروع هر سیکل |
| X12 | START_PB | شستی سبز NO | 1 = فشرده | شروع حالت اتومات |
| X13 | STOP_PB | شستی قرمز **NC** | **0 = فشرده** | توقف در پایان سیکل |
| X14 | RESET_PB | شستی آبی NO | لبه | ریست آلارم و درایورها |
| X15 | AIR_OK | پرشر سوئیچ | 1 = فشار کافی | با تأخیر ۰.۵ ثانیه‌ای برای حذف نوسان |
| X16 | GUARD_OK | پرده‌ی نوری یا گارد (از رله‌ی ایمنی) | **1 = سالم** | |
| X17 | Z_DOWN_PRINT | SMC D-M9N (اختیاری) | 1 = پد روی قطعه | با پارامتر `M501` فعال می‌شود |

## ۲-۲ خروجی‌های دیجیتال (Y)

| آدرس | نام | به کجا وصل می‌شود | توضیح |
|---|---|---|---|
| Y0 | X_PUL | CL57-X: PUL− (PUL+ به +24V، یا +5V با مقاومت) | پالس پرسرعت CH0 |
| Y1 | X_DIR | CL57-X: DIR− | جهت CH0 |
| Y2 | Y_PUL | CL57-Y: PUL− | پالس پرسرعت CH1 |
| Y3 | Y_DIR | CL57-Y: DIR− | جهت CH1 |
| Y4 | SOL_Z_DOWN | بوبین A شیر 5/2 **از طریق کنتاکت NO رله‌ی ایمنی** | پد پایین |
| Y5 | SOL_Z_UP | بوبین B شیر 5/2 (24V معمولی) | پد بالا. همیشه `Y5 = NOT Y4` |
| Y6 | X_ENABLE | رله‌ی واسط KA6 به ENA درایور X | 1 = درایور فعال. قطبیت ENA را در بخش ۶ ببینید |
| Y7 | Y_ENABLE | رله‌ی KA7 به ENA درایور Y | |
| Y10 | LAMP_GREEN | چراغ برج | ثابت = در حال تولید، چشمک = آماده |
| Y11 | LAMP_AMBER | چراغ برج | هوم نشده، حالت دستی، یا بچ تمام شده |
| Y12 | LAMP_RED | چراغ برج و بوق | آلارم |
| Y13 | AIR_MAIN | شیر Soft-Start (مثل SMC AV) | در E-Stop خاموش **نمی‌شود**. فقط با فرمان LOTO از HMI (`M119`) |
