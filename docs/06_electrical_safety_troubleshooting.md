# ۶. برق، ضد نویز، گراندینگ، مدار ایمنی و عیب‌یابی

## ۶-۱ معماری تغذیه

```
 230VAC ──[MCB 10A]──[Main Switch]──┬──[Filter EMI]──┬── PSU 48V/10A (یا 36V) ──[Fuse 10A]──┬─ CL57-X
                                    │                │        │                            └─ CL57-Y
                                    │                │   [KM1 DC contactor, کنتاکت تأخیری رله‌ی ایمنی]
                                    │                │
                                    │                └── PSU 24V/5A ─┬─[F1 2A]── PLC + HMI + رله‌ی ایمنی
                                    │                                ├─[F2 2A]── سنسورها
                                    │                                └─[F3 3A]── شیرها و چراغ‌ها (خروجی‌ها)
                                    └── PE ─────────────── شینه‌ی ارت تابلو (ستاره‌ای)
```

* **جداسازی مدارها:** 24V شیرها و بارهای سلفی را با فیوز جدا از 24V منطقی PLC و سنسورها تغذیه کنید. ایده‌آل این است که یک پاور 24V کوچک جداگانه داشته باشند.
* **0V پاورها:** 0V منبع 24V را در **یک نقطه** به PE وصل کنید (PELV). 0V منبع 48V را **به PE وصل نکنید**، مگر اینکه دفترچه‌ی CL57 خواسته باشد. این کار از حلقه‌ی زمین (Ground Loop) در مسیر برگشت جریان موتور جلوگیری می‌کند.
* **پاور 48V:** اگر 48V می‌ماند، یک **خازن ≥ 4700 µF / 100V** در ورودی هر درایور بگذارید، یا **دیود سری و Regen Clamp**. جزئیات در بخش ۱-۶ آمده است.

## ۶-۲ سیم‌بندی درایور CL57 و PLC

```
 PLC SV2 (NPN, sink)                     CL57
 ─────────────────                      ──────
 +24V ─────────────────────[R*]──────── PUL+
 Y0 ───────────────────────────────────  PUL−
 +24V ─────────────────────[R*]──────── DIR+
 Y1 ───────────────────────────────────  DIR−
 C0 (کامن Y0..Y3) ─────── 0V

 +24V ── KA6 (NC contact) ───────────── ENA+       ← Y6 رله‌ی KA6 را روشن می‌کند
 0V  ──────────────────────────────────  ENA−         (Y6=ON ⇒ NC باز ⇒ ENA بی‌جریان ⇒ درایور فعال)

 ALM+ ── +24V ;  ALM− ──────────────── X4  (با تنظیم سطح فعال ALM در ProTuner به «هدایت در حالت سالم»)
```

* **R\*:** اگر ورودی CL57 شما فقط 5V است، برای 24V مقاومت **2.2 کیلواهم ۰.۵ وات** سری بگذارید. نسخه‌های جدیدتر 24V را مستقیم می‌پذیرند (دفترچه را ببینید).
* **قطبیت ENA:** در بیشتر درایورهای Leadshine، **جریان در ENA یعنی درایور غیرفعال**. سیم‌بندی بالا طوری است که قطع برق PLC، قطع کابل یا Y6 = OFF، درایور را **غیرفعال** کند. (اگر درایور شما برعکس است، از کنتاکت NO استفاده کنید.)
* **ALM:** سیم‌بندی را طوری انجام دهید که **قطع سیم هم آلارم** دیده شود، یعنی در حالت سالم X4 = 1.
* **سیم Y0 تا Y3 تا درایور:** کابل زوج به‌هم‌تابیده‌ی شیلددار (PUL و DIR هر کدام یک زوج). **حداکثر حدود ۳ متر**. شیلد فقط **سمت PLC** به PE.
* **DIR setup time:** DDRVA قبل از پالس، DIR را تنظیم می‌کند. CL57 دست‌کم حدود ۵ µs فاصله لازم دارد که SV2 به‌طور ذاتی رعایت می‌کند.

| 5 | **فیلتر EMI تک‌فاز** ورودی 230V، نزدیک ورودی تابلو | |

| 7 | **شینه‌ی ارت ستاره‌ای**. بدنه‌ی موتورها، شاسی ماشین، درب تابلو (با بافته‌ی مسی) و PE ورودی همه به یک نقطه | |

## ۶-۴ مدار ایمنی (E-Stop و Guard)

```
                    ┌─────────────── Safety Relay (e.g. PNOZ s4 + s7.1 time-delayed) ───────────────┐
 E-Stop (2-ch NC) ──┤ S11-S12 / S21-S22                                                            │
 Light curtain OSSD ┤ (یا ماژول دوم)                                                                │
 Reset (NO)      ───┤ S33-S34                                                                      │
                    │  13-14  instant  ──── +24V → SOL-A (Y4 Z-DOWN coil feed)                     │
                    │  23-24  instant  ──── KA6 / KA7 coil feed (ENA X/Y)                          │
                    │  37-38  delayed 0.5–1 s ─── KM1 (48V drive power, Stop Cat. 1)                │
                    │  Aux NC/NO ────── X10 (ESTOP_OK)  / X16 (GUARD_OK)                            │
                    └──────────────────────────────────────────────────────────────────────────────┘
```

**ترتیب اتفاق‌ها در E-Stop:**

1. **t = 0:** رله‌ی ایمنی تغذیه‌ی بوبین Down را قطع می‌کند. PLC از طریق X10 خبردار می‌شود، Y5 (Up) روشن می‌ماند و **پد بالا می‌رود**.
2. **t = 0:** PLC با `M1078` و `M1104` پالس‌ها را فوراً قطع می‌کند و Y6 و Y7 را OFF می‌کند. کنتاکت 23-24 هم ENA را قطع می‌کند.
3. **t = 0.5 تا 1 s:** برق 48V درایورها با KM1 قطع می‌شود (Stop Category 1).
4. **هوای اصلی تخلیه نمی‌شود،** تا پد نیفتد. شیر پایلوت‌چک روی جک هم در صورت قطع هوا پد را بالا نگه می‌دارد.
5. پس از رفع E-Stop: اول Reset رله‌ی ایمنی، بعد Reset روی PLC، بعد **هومینگ**.

**پرده‌ی نوری:** نوع ۲ برای PL c یا نوع ۴ برای PL d/e، با **فاصله‌ی ایمنی** طبق ISO 13855: `S = K × T + C`، با K = 2000 mm/s. T یعنی زمان کل توقف پد، که با **تست زمان توقف** اندازه‌گیری می‌شود.

### روال عیب‌یابی فالت درایور (A02 و A03)

```
 ┌─ 1. تعداد چشمک LED قرمز CL57 را بشمارید (کدها را با دفترچه‌ی مدل خود تطبیق دهید)
 │     • Over-current    → کابل موتور (اتصال فاز به فاز یا فاز به بدنه)، موتور را با مگر تست کنید
 │     • Over-voltage    → برق برگشتی در ترمز: شتاب کمتر، 36V، خازن یا Clamp
 │     • Position error  → برو به 2
 │
 ├─ 2. Position following error
 │     a) درایور را غیرفعال کنید و محور را با دست حرکت دهید: روان است؟  (خیر ⇒ ریل، تسمه یا گیر مکانیکی)
 │     b) تسمه: کشش (فرکانس ارتعاش) و دندانه‌های پریده
 │     c) کابل انکودر: شیلد، کانکتور، فاصله از کابل موتور  (بعد از تعویض Drag Chain شایع است)
 │     d) شتاب (D526) را ۲ برابر کنید. اگر رفع شد، اینرسی یا گشتاور مرز است ⇒ گیربکس ۱:۳ یا تنظیم گین
 │     e) ProTuner: خطای پیک در سرعت کاری را ثبت کنید
 │
 ├─ 3. رفع علت، سپس [RESET] (پالس ENA ۳۰۰ ms). اگر آلارم برقرار ماند، برق 48V را قطع و وصل کنید
 │
 └─ 4. هومینگ (موقعیت معتبر نیست) ⇒ یک سیکل Dry-Run ⇒ تولید
```

### عیب‌یابی علامت‌محور (کیفیت چاپ و رفتار ماشین)

| علامت | علت محتمل مکانیکی یا کنترلی |
|---|---|
| تصویر سایه‌دار یا دوبل | لرزش X در انتهای حرکت (Settling). Z را بعد از **M25 و نشست** پایین بیاورید (`D545` را افزایش دهید). ریل X در لحظه‌ی چاپ خم می‌شود |
| تصویر کم‌رنگ | Dwell1 کوتاه، فشار کم (MGPM25)، Flash-off نامناسب، ویسکوزیته |
| تکرارپذیری موقعیت ضعیف | تسمه‌ی شل، لقی پولی (Set-Screw بدون جای تخت)، سرعت Creep هوم زیاد |
| نشتی رنگ از کاپ | کوپل صلب کاپ، شتاب زیاد Y، سایش رینگ، آهنربا ضعیف |
| محور گاهی بی‌دلیل می‌ایستد | نویز روی ورودی لیمیت (X6 و X7): کابل جدا کنید، فیلتر ورودی بگذارید |

## ۶-۶ نگهداری دوره‌ای

| دوره | کار |
|---|---|
| روزانه | تمیزی کلیشه و پد، سطح رنگ، فشار هوا، تست E-Stop |
| هفتگی | کشش تسمه‌ها، گریس ریل‌ها (HGR15 و ریل X)، تخلیه‌ی آب فیلتر هوا |
| ماهانه | پیچ سنسورهای D-M9N و سنسورهای هوم، کلمپ‌های شیلد، دمای درایورها |
| ۶ ماهه | تست زمان توقف پرده‌ی نوری، سایش رینگ کاپ، شاک‌آبزوربر |
